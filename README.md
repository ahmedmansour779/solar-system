# Solar System Three.js

A 3D Solar System simulation built with Three.js and Vite.

## Features

- Realistic planets with textures
- Planets rotate around the sun
- Self rotation for each planet
- Saturn and Uranus rings
- Space background with stars
- Interactive camera controls
- Smooth camera movement using OrbitControls
- GUI controls for:
  - Planet speed
  - Sun light intensity

## Technologies Used

- Three.js
- Vite
- JavaScript
- lil-gui
